# Prompt 管理

每个场景一个文件夹，每个 Prompt 文件带版本号。改了升版本，不覆盖旧的。

## 目录结构

```
prompts/
  persona/         # AI 人格基础指令（所有场景共用）
  onboarding/      # 引导对话
  draft/           # 草图生成
  plan/            # 计划生成
  task-deep-dive/  # 任务深挖
  profile/         # 画像总结
```

## 版本规则

- 文件名格式：`v1.0.md`
- 小改（措辞调整）升小版本：v1.0 → v1.1
- 大改（结构变化）升大版本：v1.1 → v2.0
- 每次改动在文件顶部写一行变更说明
