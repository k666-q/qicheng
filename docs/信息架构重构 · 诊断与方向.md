## 2. 诊断：为什么是迷宫

### 2.1 两个平行世界，没有主次
「计划」和「宇宙」各自是一套完整体系：两张星图（`/universe`、`/plan/universe`）、两个学习页（`/universe/learn`、`/plan/learn`）、计划侧还有自己的情绪曲线、卡片、首日引导。用户不知道该走哪条线，也不知道两条线的关系。此前用 `from` 参数缝合两边，是在给迷宫加路标，不是拆墙。

### 2.2 三个"开始"
`/onboarding`、`/first-day`、`/universe?welcome=1` 都是新用户首次引导，走哪个取决于从哪个门进。

### 2.3 五个平级入口，没有一个回答"我现在该做什么"
登录后直接落到 `/universe`——一张漂亮的星图，然后呢？

### 2.4 概念词汇过载
星、周目、回响、种子、债、巨人、能力点、里程碑、旅程卡、情绪曲线、造物主、缺口、导游/教练/对手/回声……每个单独看都有道理，加在一起用户要学一门新语言才能用产品。多周目系统本身又新增了 8 个名词。

### 2.5 根因
功能是一条条请求垒上去的，从来没定义过"那一个循环"。每次都是"加一个 X"，X 本身做得不差，但没人问过 X 在用户一天里的哪一分钟出现、替代了什么。

## 3. 方向：一根脊柱，一个循环，三个入口

### 3.1 脊柱（用户唯一需要理解的主线）

```
目标 → 路线（计划） → 今天这一颗星 → 学它（周目） → 回到「今天」
```

### 3.2 首页改成「今天」
不是星图。一屏回答三件事：
1. 我在学什么目标
2. 今天该碰哪颗星（第几周目、为什么是它）
3. 点一下就进去

星图、成长、笔记全部退到第二层。

### 3.3 导航砍到三个：今天 / 星图 / 我的
- **星图**只保留一张，计划范围用高亮筛选表达；删除 `/plan/universe`。
- **我的**收编 `profile`、`growth`、`cards`、`notes`、`curve`——tab 组织，或只保留有数据的部分。
- 两个学习页合并为一条路由，返回永远回「今天」。

### 3.4 开始只有一个
onboarding 说完目标 → 直接生成计划 → 直接落到「今天」。`first-day` 并入 onboarding，`?welcome=1` 分支删除。

### 3.5 概念做减法 + 渐进披露
- 用户必须学的词只留三个：**目标、星、周目**。
- 回响、种子、债、巨人等**不删功能，但不预先介绍**：第一次出现时原地一行字解释。
- 部分能力按进度解锁：如「回响」第 2 周目才出现；「成长」点亮 3 颗星后才出现在「我的」。

### 3.6 顺手清掉
- 未挂载的 `CosmicNav`
- 情绪曲线全页（并入「我的」）
- `?welcome=1` 分支
